The 20 laws typecheck (`bend LAWS.bend --check-only` reports 20 unproven laws) and match Base. Nothing below is a false equation. The gaps are facts a packed-bytes proof needs and shapes that do not rewrite the terms those proofs contain.

1. **`W.wrap` / `of_nat` / `inc` / `add` / `mul` / `shl` / `shln` — should fix.** Every non-overflow result is stuck under `W.wrap`. There is no law that `Nat.mod(n, 2^32) = n` when `n < 2^32`, and no round-trip. For `a` with `W.n(a) = 5`, `inc` rewrites to `W.wrap(6)`, which is `Nat.mod(6, 2^32)`, and nothing identifies that with `6`. The same block hits a loop counter, `U32.from_nat` of a Nat index below `2^32`, and `from_nat(W.n(a)) == a`. Add:
   - `h: Nat.is_lt(n, W.two32()) == True` ⇒ `{W.wrap(n) == n : Nat}`
   - `{U32.from_nat(W.n(a)) == a : U32}`

2. **`sub` — should fix.** The equation is true (`Word.sub` is `a + ~b + 1`, i.e. `(a + 2^32 - b) mod 2^32`, and `a + 2^32 >= 2^32 > W.n(b)`, so `Nat.sub` does not truncate). The shape still will not simplify the common case. `W.n(U32.sub(5, 3))` becomes `W.wrap(2^32 + 2)`. That quantity is `>= 2^32`, so the lemma in finding 1 does not apply. The borrow case does: `U32.sub(3, 5)` is `W.wrap(2^32 - 2)` and the lemma yields `2^32 - 2`. Add the non-borrow form proofs actually rewrite with: `h: U32.is_le(b, a) == True` ⇒ `{W.n(U32.sub(a, b)) == Nat.sub(W.n(a), W.n(b)) : Nat}`. Decrement of a counter is this with `b = 1`.

3. **`and_low` — should fix.** A mask of the low `k` bits is `2^k - 1`, and the equality holds for `k = 0` (`and` with `0`, `Nat.mod` by `1`, both `0`) and `k = 32` (all-ones, `Nat.mod` by `2^32`). Two use problems:
   - The hypothesis `k <= 32` is not required. For `k = 33`, `a = 1`: `(2^33 - 1) mod 2^32 = 2^32 - 1`, so the mask is all-ones, and both sides are `1`. Drop `hk`.
   - The left side only matches `U32.and(a, U32.from_nat(Nat.pow(2, k) - 1))`. Byte offset `i & 3` and a byte mask `w & 255` are literals. `3` is not that `from_nat` term. State the mask by its value: `h: {W.n(m) == Nat.sub(Nat.pow(2n, k), 1n) : Nat}` ⇒ `{W.n(U32.and(a, m)) == Nat.mod(W.n(a), Nat.pow(2n, k)) : Nat}`. `U32.to_nat(255)` and `U32.to_nat(3)` are small computations; unfolding `from_nat` 255 times is not.

4. **`or_disjoint` — should fix.** The law is true: no shared bit means no carry, the sum is `< 2^32`, and `W.n(U32.or(a, b)) = W.n(a) + W.n(b)` (no wrap). It does not give the hypothesis that packing needs. For bytes `b0..b3` each `< 256`,
   `b0 | (b1 << 8) | (b2 << 16) | (b3 << 24)`
   equals `b0 + b1·2^8 + b2·2^16 + b3·2^24` (max is `2^32 - 1`). `U32.shln(b1, 8)` has low 8 bits clear, but no law says `U32.and(U32.shln(a, k), low_k_mask) == 0`. Add that (true for every `k`: the product is divisible by `2^k`, and for `k >= 32` the shift is already `0`), and add one `pack4` law whose right side uses `Nat.pow(2n, 8n)`, `Nat.pow(2n, 16n)`, `Nat.pow(2n, 24n)`. A Nat literal past `256n` is `U32.to_nat` underneath, so `65536n` is the wrong way to write the coefficient.

5. **`of_nat` — should fix.** `of_nat` already says `W.n(U32.from_nat(x + y)) = W.wrap(x + y)`. It does not say the word `U32.add(U32.from_nat(x), U32.from_nat(y))` is `U32.from_nat(x + y)`. `add` only produces `W.wrap(W.wrap(x) + W.wrap(y))`. Closing that needs `W.wrap(W.wrap(x) + W.wrap(y)) = W.wrap(x + y)`, which is not here. Concrete: `x = 2^32 - 1`, `y = 2`. Both `U32.add(max, 2)` and `U32.from_nat(2^32 + 1)` are `1`, and `W.wrap(x + y) = 1`. Add `{U32.add(U32.from_nat(x), U32.from_nat(y)) == U32.from_nat(Nat.add(x, y)) : U32}` and the same for `U32.mul` / `Nat.mul`. Do not add the `Nat.sub` analogue: `Nat.sub(0, 1) = 0` so `from_nat` is `0`, while `U32.sub(0, 1) = 2^32 - 1`.

6. **`U32.min`, `U32.max`, `U32.div`, `U32.mod` — should fix.** None of these follow from the shift and mask laws. Base defines them as:
   - `W.n(U32.min(a, b)) = Nat.min(W.n(a), W.n(b))` (`Bool.pick` of `U32.is_lt`). Same for `max`. `min(5, 3) = 3`.
   - `W.n(U32.div(a, b)) = Nat.div(W.n(a), W.n(b))` and `W.n(U32.mod(a, b)) = Nat.mod(W.n(a), W.n(b))`, with no `b ≠ 0` premise. Both sides agree at `0`: `U32.div(7, 0) = 0` and `Nat.div(7, 0) = 0`; `U32.mod(7, 0) = 7` and `Nat.mod(7, 0) = 7` (`Nat.divmod` returns `(0, a)` when the divisor is `0`). `U32.div(7, 2) = 3`, `U32.mod(7, 2) = 1`. The restoring divider keeps the remainder `< b`, including when the shifted remainder temporarily exceeds `2^32`.
   - `i >> 2` is already `shrn`: `W.n(U32.shrn(i, 2)) = Nat.div(W.n(i), 4)`. Byte offset `i & 3` is finding 3 with `k = 2`. `div`/`mod` are for the operations themselves, not for that index split.

7. **`bit_and`, `bit_or`, `bit_xor`, `bit_not` — should fix.** The bit equations are true for `k >= 32` as well (`W.bit` is `0` there, and `bit_not`’s `k < 32` guard is required: without it, `k = 32`, `a = 0` gives `W.bit(U32.not(0), 32) = False` on the left and `Bool.not(False) = True` on the right). They quantify a single `k`. No law says “`W.bit(a, k) = W.bit(b, k)` for every `k < 32` implies `a == b`”, and no law rebuilds `W.n` from bits, so these four cannot prove a word equality or a `W.n` goal. `same` only fires from numbers. `not` has a one-line numeric form the bit law does not reach: `{W.n(U32.not(a)) == Nat.sub(Nat.sub(W.two32(), 1n), W.n(a)) : Nat}`. Check: `U32.not(0) = 2^32 - 1`, `U32.not(1) = 2^32 - 2`. Add that, plus bit extensionality for the other three.

8. **`eq` / `lt` / `le` — minor.** These three match `Word.cmp` (higher bits first, `False < True`). `U32.is_ne(a, b)` is already `Bool.not(U32.is_eq(a, b))` by the two defs, so `ne` needs no law. `U32.is_gt(a, b)` is not `U32.is_lt(b, a)` by unfolding (`Cmp.is_gt` vs `Cmp.is_lt` on a swapped `Word.cmp`). Add `{U32.is_gt(a, b) == Nat.is_gt(W.n(a), W.n(b)) : Bool}` and the same for `is_ge`. `is_gt(2, 1) = True`, `is_gt(1, 1) = False`.

9. **Names — minor.** `add`, `eq`, `lt`, `sub` are the same verbs as `U32.add`, `U32.is_eq`, and so on. Under `import … as W` that is workable (`W.add` next to `U32.add`). The defs are already called `W.n`, and `LAWS.bend` imports them as `D`, so a second import of `defs.bend` as `W` makes the number `W.W.n` while the law text says `D.W.n`. Publish one entry that exposes `n`, `wrap`, `bit`, `two32` and the laws under a single alias.
